What the component research found

OptionHow it worksFit here
shadcn shimmerOfficial pure-CSS utility. Clips a moving gradient to text, follows currentColor, supports RTL and reduced motion.Best fit; used in B and C. No React wrapper or animation runtime is needed.
AI Elements ShimmerPolymorphic React text component with Motion and configurable duration/spread.Useful for richer AI chat elements; more machinery than these rows need.
shadcn.io Shimmering TextThird-party text effect with per-character color animation and optional wave.More decorative; character wrappers are unnecessary for compact truncated PR titles.

These are design previews, not a new app setting. The current row implementation is preserved in PR #32949; text options are kept here for comparison. All options retain the accessible stale label and have the same row footprint. Reduced motion renders text normally and keeps A’s still tint. Ongoing shimmer can imply active work, while the current state means cached/stale data—consider limiting animation to actual refreshes if that distinction matters.
